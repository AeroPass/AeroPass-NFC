# AeroPass-NFC
En este repositorio se encuentra todo un proyecto NFC dedicado al acceso mediante medios fisicos

## Iniciar el backend

Desde la raíz del repositorio, ejecuta `npm run start:dev`. Antes, instala las dependencias
del backend con `npm install` desde `backend` y configura `backend/.env` según
[la guía del backend](backend/README.md).
